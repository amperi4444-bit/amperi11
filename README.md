# Умный Калькулятор Систем Безопасности

Telegram бот для расчета смет по системам безопасности (видеонаблюдение, СКУД, пожарная и охранная сигнализация).

## Возможности

### ✅ Готовые разделы:
- **🎥 Видеонаблюдение** - полный расчет камер, регистраторов, архива, прокладки кабеля
- **🔑 СКУД** - контроллеры, замки, считыватели, доводчики, питание

### 🚧 В разработке:
- **🔥 Пожарная сигнализация** (по ТКП)
- **🛡️ Охранная сигнализация** (по ТКП)

## Особенности

- **Два файла на выходе:**
  - **PDF** - коммерческое предложение (отправляется клиенту)
  - **Excel** - детальная смета со всеми коэффициентами и параметрами (для внутреннего использования)

- **Учет всех параметров:**
  - Высота монтажа (обычная / высотная +30%)
  - Стесненность (+25%)
  - Тип прокладки (стена / потолок)
  - Тип основания (гипсокартон / кирпич / бетон)
  - Размеры гофры и коробов (16/20/25/32 мм)

- **Современный дизайн:**
  - Темная цветовая схема (navy/slate)
  - Адаптивная верстка
  - Интерактивные элементы
  - Счетчики и селекторы

## Установка

### 1. Установите зависимости:

```bash
pip install -q aiogram reportlab openpyxl
```

### 2. Настройте бота:

Откройте `telegram_bot.py` и укажите:
- `BOT_TOKEN` - токен вашего бота
- `ADMIN_TELEGRAM_ID` - ваш Telegram ID
- `WEBAPP_URL` - URL веб-приложения (GitHub Pages или другой хостинг)

### 3. Разместите HTML:

Разместите `index.html` на GitHub Pages или любом другом хостинге с HTTPS.

### 4. Запустите бота:

```bash
python telegram_bot.py
```

## Как работает

1. Пользователь открывает бота командой `/start`
2. Нажимает кнопку "🧮 Открыть калькулятор"
3. Заполняет данные в веб-интерфейсе
4. Нажимает "📄 Сформировать КП и Смету"
5. Получает:
   - **PDF** с коммерческим предложением
   - **Excel** с детальной сметой и коэффициентами
6. Администратор получает копию Excel-сметы

## Цены в базе данных

Все цены хранятся в SQLite (`database.db`) в таблице `prices`. 

Вы можете изменить цены:
1. Открыв базу данных любым SQLite редактором
2. Или изменив значения в функции `init_db()` в файле `telegram_bot.py`

### Основные категории цен:

- `work_*` - стоимость работ
- `equip_*` - стоимость оборудования
- `consumables_*` - расходные материалы
- `material_*` - материалы (гофра, короб)
- `coef_*` - коэффициенты

## Пример использования

### Видеонаблюдение:
```
Клиент: ООО "Рога и Копыта"
- 4 внутренние камеры (HiWatch)
- 2 уличные камеры (HiWatch)
- Регистратор PoE 8 портов
- HDD 4 ТБ
- Монитор
- Прокладка 50м в гофре 16мм
- Высота: обычная
- Основание: бетон
```

**Результат:** PDF с КП + Excel с детализацией и коэффициентами.

### СКУД:
```
Клиент: Офисный центр
- Контроллер на 2 двери
- 2 электромагнитных замка 180 кг
- 2 доводчика до 120 кг
- 4 считывателя
- 20 брелков
- Блок питания 3 Ah
- Аккумулятор 7 Ah
```

**Результат:** PDF с КП + Excel с полной сметой.

## Поддержка кириллицы в PDF

Бот автоматически пытается использовать шрифт DejaVuSans для корректного отображения кириллицы в PDF.

Если шрифт не найден, используется fallback на Helvetica (может некорректно отображать русский текст).
